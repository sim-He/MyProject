# 公告雷达

一个本地运行的 Windows 桌面应用：定时检查多个官网公告栏，识别新增公告、生成本地摘要，并按指定浏览器打开原文。

## 功能

- 添加任意数量的公告栏 URL，首次检查只建立历史基准
- 定时或手动检查，按标题与规范化 URL 去重
- 自动提取公告正文并生成无需 API 的本地摘要
- 应用内未读、来源、日期和摘要聚合展示
- 链接右键菜单：打开网页、立即检查、复制链接、暂停监测
- APP 默认浏览器与单链接浏览器设置；单链接设置优先
- 自动识别 Edge、Chrome、Firefox，也可选择其他浏览器的 `.exe`
- 桌面通知、开机启动、监测间隔设置
- 所有数据保存在 Electron 的用户数据目录，不上传服务器

## 开发运行

```powershell
npm install
npm start
```

## 打包 Windows 安装包和便携版

```powershell
npm run dist
```

产物会生成在 `dist` 目录。

## 说明

部分网站使用验证码、登录、严格反爬策略或完全由 JavaScript 动态渲染，这类页面可能无法直接读取。当前版本面向公开可访问的 HTML 公告栏；本地摘要是抽取式摘要，不依赖第三方 AI 服务。
